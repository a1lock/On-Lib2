# OnLib2 - Онлайн-библиотека на Django

Это MVP (минимально жизнеспособный продукт) веб-приложения онлайн-библиотеки, созданный с использованием Python и фреймворка Django. Проект демонстрирует классический подход к веб-разработке с рендерингом страниц на стороне сервера (Server-Side Rendering).

## Основные возможности

*   **Аутентификация пользователей:** Полный цикл регистрации, входа и выхода на базе встроенной и безопасной системы Django.
*   **Каталог книг:** Просмотр всех книг в библиотеке с возможностью динамического поиска по названию и автору.
*   **Страницы книг:** Детальная информация о каждой книге, включая обложку, описание и автора.
*   **Интерактивная система отзывов:** Авторизованные пользователи могут оставлять отзывы к книгам, которые сразу же отображаются на странице.
*   **Загрузка изображений:** Реализована загрузка обложек для книг через админ-панель.
*   **Управление контентом:** Простое добавление, редактирование и удаление книг и отзывов через стандартную админ-панель Django.

## Технологический стек

*   **Бэкенд:** Python 3, Django
*   **Фронтенд:** HTML5, CSS3
*   **База данных:** SQLite 3 (в режиме разработки)
*   **Библиотеки:** Pillow (для обработки изображений)

## Архитектурный подход

Проект построен как **монолитное приложение**. Вся логика, включая обработку запросов, взаимодействие с базой данных и генерацию HTML-страниц, выполняется на стороне сервера. Это позволяет добиться быстрой разработки, простоты развертывания и высокой производительности для проектов такого масштаба.

## Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
    cd ВАШ_РЕПОЗИТОРИЙ
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    # Для Windows
    python -m venv venv
    venv\Scripts\activate

    # Для macOS/Linux
    python3 -m venv venv
    source venv/bin/activate
    ```

3.  **Установите зависимости:**
    ```bash
    pip install Django Pillow
    ```
    *(Примечание: в проекте остались зависимости от `djangorestframework`, но они не используются для рендеринга страниц).*

4.  **Примените миграции базы данных:**
    ```bash
    python manage.py migrate
    ```

5.  **Создайте суперпользователя для доступа к админ-панели:**
    ```bash
    python manage.py createsuperuser
    ```

6.  **Запустите сервер для разработки:**
    ```bash
    python manage.py runserver
    ```

После этого проект будет доступен в вашем браузере по адресу `http://127.0.0.1:8000/`. Админ-панель будет доступна по адресу `http://127.0.0.1:8000/admin/`.
